# Проект: демо-сайт барбершопа

## План
Разрабатываю цифровые решения (сайты, Telegram-боты, системы записи, автоматизация) для локального бизнеса красоты/барберов. Сначала делаю ОДИН отполированный демо-кейс — сайт барбершопа — как портфолио для продаж. Барбершоп выбран для демо, потому что хорошо фотографируется и презентуется (сильные "до/после", мужская эстетика) — но продавать буду не барбершопам.

## Кому реально продаю
Целевые клиенты для холодных звонков — парикмахерские и совмещённые студии стрижки+маникюра, независимые (не сети), не барбершопы (барбершопы в моём регионе чаще сети — медленнее продавать). Цель: первые 3 платных клиента, дальше решаю по специализации.

## Референсы дизайна/структуры (изучены)
Барбершопы: dabro.hair, metrobarber.ru/omsk, alpacino55.ru — хорошие паттерны: жирная типографика, галереи "до/после", блок "почему мы", понятные цены, простая запись в 3 шага, органичные переходы между блоками.
Салоны красоты: iris55.ru, extendess.ru, beautick.ru.

## Рынок бронирования
YCLIENTS, DIKIDI Business и "1С:Салон красоты" — все сосуществуют, единого лидера нет, поэтому своя система записи — не лишнее, а закрывает реальный пробел для бизнеса без платной CRM.

## База лидов
Есть готовый список 10 реальных салонов/барбершопов (Омск, Москва, СПб) без сайта — с хорошими отзывами/фото/каталогом услуг, для контента демо-кейса и холодных звонков.

## Инструментарий дизайна для этого проекта
- shadcn/ui (github.com/shadcn-ui/ui) — базовый UI-кит компонентов
- emilkowalski/skills — вкус в дизайне/анимациях (emil-design-eng, apple-design, animate)
- vercel-labs/agent-skills — web-design-guidelines, vercel-react-best-practices

## Дизайн-инструменты проекта (использовать ВСЕГДА при любой работе с UI/дизайном, без напоминаний)

Skills (.claude/skills/):
- frontend-design (Anthropic) — обязательно применять перед написанием любого UI-кода: сначала явно зафиксировать шрифты/цвета/движение/композицию, избегая клише ИИ-дизайна, и только потом кодить
- webapp-testing (Anthropic) — после каждого визуального изменения открывать сайт в браузере через Playwright, делать скриншот и визуально сверять результат, а не считать задачу выполненной вслепую
- ui-ux-pro-max — использовать базу стилей/палитр/шрифтовых пар (в т.ч. пресеты под нишу Beauty/Spa) при выборе визуального направления
- emilkowalski/skills (animate, apple-design, review-animations и др.) — для микро-анимаций и ревью движения
- vercel-labs/agent-skills (web-design-guidelines, vercel-react-view-transitions и др.) — для вёрстки и переходов

Правило: перед началом любой визуальной доработки — свериться с этим списком и явно указать, какие из скиллов применяются к текущей задаче.

Вместе с ui-ux-pro-max установился его пакет: design, design-system, ui-styling, brand, banner-design, slides. Подключать по профилю задачи (токены, брендинг, баннеры, презентации).

### Восстановление скиллов на новой машине

Папки `.claude/skills/` и `.agents/skills/` в git не хранятся. После клона:

```
npx skills experimental_install      # 24 скилла по skills-lock.json
npm install -g ui-ux-pro-max-cli && uipro init --ai claude   # ui-ux-pro-max и его пакет (7 шт.)
```
